# 아이보리·코발트 반응형 웹

적용일: 2026-11-07.

슬라이드 덱의 아이보리 배경, 코발트 강조색, 굵은 제목과 사각 패널을 스크롤형 웹 레이아웃에 적용했습니다. 콘텐츠 JSON과 개조식 표현, 기존 25개 수행 작업·수치·원본 링크를 그대로 사용합니다.

## 페이지 구성

- 홈: 소개와 프로젝트 바로가기 → 프로젝트 카드 → 배경·기술 → 연락처
- 프로젝트 상세: 개요·역할·기술과 도식 → 데이터 규모·설정 → 작업 그룹과 코드 링크 → 다른 프로젝트
- 슬라이드: `/#/deck`에서 기존 20장 덱 제공; `portfolio.html` 단일 파일 저장도 유지

프로젝트 순서는 덱의 개요 순서에서 가져오며, 작업 그룹은 `presentation.slides`의 기존 연결을 사용합니다. 작업 카드와 도식을 웹·덱에서 공유해 내용이 서로 달라지지 않도록 합니다.

## 반응형 배치

- 넓은 화면: 홈·상세 개요 2단, 프로젝트 카드 2열, 상세 작업 2열과 고정 목차
- 태블릿: 홈 소개와 프로젝트 바로가기 분리, 작업 카드 1열
- 모바일: 전체 1열, 상단 접이식 메뉴, 페이지 안 목차와 자연스러운 세로 스크롤

웹페이지에서는 휠·방향키로 슬라이드를 넘기는 동작이 실행되지 않습니다. 해당 기능은 덱 경로에서만 사용합니다. 이전 프로젝트 URL과 `section` 링크, 이전 루트 덱의 `slide` 링크도 해당 내용으로 연결합니다.
