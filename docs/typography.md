# 웹 포트폴리오 가독성 기준

적용일: 2026-11-08. 홈·기술 스택·프로젝트 목록·상세 및 시각화 화면에 공통 적용한다.

- 본문은 16px 이상, 메뉴·연락처·분류·숙련도·링크·캡션 등 보조 문구는 14px 이상으로 표시한다.
- 모바일에서도 글자 크기를 줄여 내용을 맞추지 않는다. 줄바꿈·열 수·간격·자연스러운 세로 스크롤로 배치한다.
- 반복되는 브랜드 보조 문구와 기술 분류 표기는 덜어내고 기술명·숙련도를 유지한다.
- ERD는 기본 100% 배율과 가로 이동을 사용한다. 컬럼명·키·타입이 겹치지 않도록 테이블과 행 간격을 확보한다.
- SVG 흐름도와 비교 도식은 텍스트가 축소되지 않는 최소 표시 너비를 유지하고, 좁은 화면에서는 도식 내부를 가로 이동한다.

공통 규칙은 `src/typography.css`, 화면별 크기는 각 CSS에 둔다. 새 화면에서는 계산된 글자 크기와 SVG 변환 배율을 함께 확인한다.
